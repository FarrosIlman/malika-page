# Malika Digital Solutions - Official Website

Selamat datang di repositori resmi **Malika Digital Solutions**. Ini adalah _landing page_ perusahaan yang dibangun dengan teknologi modern untuk menghadirkan performa tinggi, animasi yang mulus, dan optimasi SEO tingkat lanjut.

## 🚀 Tech Stack Utama

Website ini menggunakan _tech stack_ terkini:
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animasi**: [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scrolling**: [Lenis](https://lenis.studiofreight.com/)
- **Ikon**: [Lucide React](https://lucide.dev/)
- **CMS**: [Sanity](https://www.sanity.io/) (via `next-sanity`)
- **Deployment & Analytics**: [Vercel](https://vercel.com/) (Analytics & Speed Insights terintegrasi)

## 💡 Fitur Unggulan

- **Optimasi SEO Tingkat Lanjut**: Dilengkapi dengan Schema Markup JSON-LD (WebSite, Organization, LocalBusiness), Metadata global, Canonical URLs, dan Sitemap dinamis. Dirancang untuk pencarian lokal di Pekalongan hingga audiens global (Worldwide).
- **Desain Responsif & Modern**: UI/UX kelas atas yang memanjakan mata, cocok untuk profil perusahaan *Software House* & *Digital Agency*.
- **Performa Tinggi**: Di-compile menjadi *static pages* yang ringan dan cepat.

## 🛠️ Cara Menjalankan Secara Lokal

Pastikan Anda telah menginstal [Node.js](https://nodejs.org/) (minimal v18+ disarankan).

1. Clone repositori ini dan masuk ke direktori:
   ```bash
   git clone <repository_url>
   cd malika-page
   ```

2. Instal dependensi:
   ```bash
   npm install
   ```

3. Jalankan _development server_:
   ```bash
   npm run dev
   ```

4. Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

## 📈 Struktur Proyek

- `/src/app`: Konfigurasi rute Next.js, _global layout_ (`layout.tsx`), _page-level SEO_, sitemap, dan manifest.
- `/src/components`: Komponen-komponen UI yang dapat digunakan kembali (_reusable_).
- `/src/sections`: Berbagai seksi penyusun halaman (Hero, Tech Stack, Fitur, Testimonial, dsb).
- `/src/config`: Konfigurasi situs utama seperti SEO Meta Tags dan daftar link (`site.ts`).
- `/src/sanity`: Konfigurasi konten untuk integrasi dengan Sanity CMS.
